# Las tecnologias utilizadas en esta solucion son: React Native, Zustand para manejo de estados, Zod para validaciones, Hooks personalizados para manejo de logica, Reac Navigation para navegacion, Nativewind para manejar estilos, Tailwind CSS para estilos, TypeScript, TypeORM con SQL Lite para manejo de persistencia local, Axios para peticiones y React Query, Rxjs para observabilidad, y componentes personalizados

<!-- Arquitectura -->

# Los patrones utilizados en esta solucion es la tipica de una aplicacion de react con componentes, layouts, screens, navigators, services, stores, types, styles

<!-- Formularios -->

# Los formularios se vienen manejando de la siguiente manera: Se utiliza un hook personalizado para manejar la logica del formulario, para validar se utiliza zod y se coloca en la carpeta de validations en su archivo correspondiente, para manejo de los estados de los input se utiliza un hook personalizado llamado useForm y asi necesito que se siga haciendo.

<!-- La aplicacion es de -->

# Esta es una aplicacion de react native que se encarga de realizar marcajes de personal de proyectos la cual recolecta la informacion por medio de Gps y compara esa ubicacion o espera que este cerca de la ubicacion de los proyectos correspondientes, esto para tener un control de marcajes de el personal.

<!-- Nos enfocaremos por el momento en -->

# Nuestro principal enfoque es lograr una experiencia de usuario perfecta, necesitamos mejorar el disenio de la aplicacion existente, agregando temas claro y oscuro personalizables, que el mantenimiento en desarrollo sea flexible, mejorar el estilo de cada uno de los componentes existentes con el fin de mejorar la UI y que el usuario sienta que esta utilizando un app moderna, tenemos que tener compatibilidad con la mayor parte de dispocitivos asi que tenemos que manejar lo responsive de la mejor forma para que no hay problemas con los distintos tipos de pantallas existentes en cada telefono o en cada version de android, manejemos como diseniadores especialidados en la calidad y modernidad de la experiencia de cada usuario para que sea un placer poder utilizar la aplicacion.
